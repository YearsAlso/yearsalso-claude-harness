# 应用范围守卫（Web 栈）

多应用共仓/伴生项目时，**每个前端应用只在自己的目录边界内改动**，禁止越界创建页面/入口/路由。

## 规则

1. 应用范围声明在 profile 的「栈上下文」段（如：`web-app-scope: 仅管理后台 SPA，不含官网公开页`）
2. 禁止在本应用内创建范围外的页面（即使"顺手就能做"）
3. 禁止在构建配置中添加范围外的 entry point
4. 禁止添加与外部应用路由前缀冲突的路由（如外部项目独占 `/download`）

## 范围外能力如何提供

跨应用的能力（如公开下载）通过 **API 暴露**，由归属应用自行渲染 UI：

- 本应用只读预览可以调用，但不提供面向外部用户的界面
- 接口契约（路径/字段）变更需同步消费方

## 越界需求处理

用户请求落在范围外 → 报告范围边界 + 指出归属项目 + 询问是否转去对应项目处理，**不得私自实现**。
